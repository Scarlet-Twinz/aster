# ASTER

**General-purpose programming language and compiler built from scratch in Rust.**

ASTER implements a complete source-to-execution pipeline, including lexical analysis, parsing, AST construction, semantic analysis, bytecode generation, and virtual-machine execution.

---

## Product Preview

ASTER exposes the stages of compilation directly:

```text
Source Code
    │
    ▼
  Lexer
    │
    ▼
  Tokens
    │
    ▼
  Parser
    │
    ▼
   AST
    │
    ▼
Semantic Analysis
    │
    ▼
  Bytecode
    │
    ▼
Virtual Machine
```

The CLI can inspect the AST and generated bytecode, making the intermediate representations visible rather than treating compilation as a black box.

## Core Features

### Language foundation

- Token model and lexer
- Recursive-descent parser with operator precedence
- Abstract syntax tree
- Variables and assignments
- Explicit variable type annotations
- Blocks and conditional statements
- Functions, parameters, calls, and returns
- Lexical scopes

### Semantic analysis

- `number`, `string`, `bool`, `void`, and `unknown` types
- Duplicate declaration detection
- Undefined variable and function detection
- Function arity checking
- Duplicate parameter detection
- Operator type checking
- Assignment type checking
- Explicit annotation validation
- Non-boolean conditional validation

### Execution engine

- Bytecode instruction set
- Bytecode compiler
- Stack-based virtual machine
- Global variables
- Local variable slots
- Function call frames
- Recursive function calls
- Conditional jumps
- Runtime values
- Bytecode disassembler

### Developer experience

- `--check` semantic validation
- `--dump-ast` AST inspection
- `--dump-bytecode` bytecode inspection
- `--repl` interactive mode
- Structured compiler errors
- Parser/lexer source locations
- Regression tests across frontend, semantics, execution, and disassembly
- GitHub Actions CI

## Example

```text
let answer: number = 40 + 2;

if answer > 0 {
    print(answer);
}
```

Running the program produces:

```text
42
```

ASTER also supports explicit types:

```text
let answer: number = 42;
let message: string = "hello";
let enabled: bool = true;
```

A mismatched annotation is rejected during semantic analysis before bytecode generation.

## CLI

Run a program:

```bash
cargo run -- examples/hello.aster
```

Check semantics without executing:

```bash
cargo run -- --check examples/hello.aster
```

Inspect the AST:

```bash
cargo run -- --dump-ast examples/hello.aster
```

Inspect generated bytecode:

```bash
cargo run -- --dump-bytecode examples/hello.aster
```

Start the REPL:

```bash
cargo run -- --repl
```

Inside the REPL:

```text
aster> :help
aster> :quit
```

## Architecture

```text
                         ┌─────────────────────┐
                         │     ASTER Source     │
                         └──────────┬──────────┘
                                    │
                                    ▼
                         ┌─────────────────────┐
                         │        Lexer        │
                         └──────────┬──────────┘
                                    │
                                    ▼
                         ┌─────────────────────┐
                         │       Parser        │
                         └──────────┬──────────┘
                                    │
                                    ▼
                         ┌─────────────────────┐
                         │        AST          │
                         └──────────┬──────────┘
                                    │
                                    ▼
                         ┌─────────────────────┐
                         │ Semantic Analyzer   │
                         └──────────┬──────────┘
                                    │
                                    ▼
                         ┌─────────────────────┐
                         │ Bytecode Compiler   │
                         └──────────┬──────────┘
                                    │
                                    ▼
                         ┌─────────────────────┐
                         │  Stack VM + Frames  │
                         └─────────────────────┘
```

The implementation uses Rust-managed values and call frames. ASTER therefore exposes a stack-machine execution model while relying on Rust for memory safety in the compiler and runtime implementation.

## Getting Started

### Prerequisites

Install a current stable Rust toolchain with Cargo.

Verify:

```bash
rustc --version
cargo --version
```

### Clone and build

```bash
git clone https://github.com/Scarlet-Twinz/aster.git
cd aster
cargo build
```

### Run the example

```bash
cargo run -- examples/hello.aster
```
