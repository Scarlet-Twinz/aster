# ASTER

**ASTER** is a general-purpose programming language and compiler built from scratch in Rust.

ASTER is a real compiler pipeline, not a syntax-only demo:

`source → lexer → parser → AST → semantic analysis → bytecode → virtual machine`

## Explicit types

ASTER supports optional explicit type annotations on variables:

```text
let answer: number = 40 + 2;
let message: string = "hello";
let enabled: bool = true;
```

The semantic analyzer rejects mismatched annotations before bytecode generation.

## Example

```text
let answer: number = 40 + 2;

if answer > 0 {
    print(answer);
}
```

Execute it:

```text
cargo run -- examples/hello.aster
```

Inspect the AST:

```text
cargo run -- --dump-ast examples/hello.aster
```

Inspect generated bytecode:

```text
cargo run -- --dump-bytecode examples/hello.aster
```

Run semantic analysis without execution:

```text
cargo run -- --check examples/hello.aster
```

Start the REPL:

```text
cargo run -- --repl
```

## Architecture

```text
Source
  ↓
Lexer
  ↓
Tokens
  ↓
Parser
  ↓
AST
  ↓
Semantic Analyzer
  ↓
Bytecode Compiler
  ↓
Bytecode
  ↓
Virtual Machine
```

The VM uses Rust-managed values and call frames, keeping memory safety in the implementation language while exposing a real stack-machine execution model.
